==============================================================
                    AutoClicker - READ ME
==============================================================
                             Türkçe için: OKU-BENI.txt

The AutoClicker.exe in this folder clicks the mouse for you.
Press a key and it keeps clicking until you stop it.


1) OPENING THE APP
--------------------------------------------------------------
Double-click AutoClicker.exe.

IMPORTANT: do not move AutoClicker.exe somewhere else on its
own. It cannot start without the "_internal" folder beside it.
If you need to move it, move the whole folder.


2) THE WINDOWS THAT APPEAR ON THE FIRST RUN
--------------------------------------------------------------
Up to two windows can show up. Both are normal.

* A blue window saying "Windows protected your PC":
  This means Windows has not seen the program before, not
  that it is harmful. Click the small "More info" text, then
  press "Run anyway".

* A window asking you to allow the program to make changes
  to your device:
  Say "Yes". If you refuse, the app still opens, but its
  clicks will not work in some games, because Windows blocks
  unprivileged programs from sending clicks into them.


3) USING IT
--------------------------------------------------------------
Click Interval : How long between clicks. Four boxes:
                 Hours / Min / Sec / ms (milliseconds).
                 100 ms = ten clicks per second.
                 For something slow, put 1 in the Sec box.
                 Digits only.

Click Type     : Single -> a normal click
                 Double -> a double click
                 Hold   -> holds the button down
                           (mining, continuous fire, and so on)

Mouse Btn      : Which button is sent - Left / Right / Middle

Hotkey         : The start-stop key, F6 to begin with.
                 To change it, click the button and then press
                 the key you want. Mouse side buttons work too.
                 Esc cancels.

TO START:
  1. Move the mouse pointer over the thing you want clicked.
  2. Press F6. (Or click the blue START bar.)
  3. Press F6 again to stop.

Clicks go wherever the pointer is sitting, so put the pointer
in place first, then start.


4) WHAT THE STRIP AT THE BOTTOM MEANS
--------------------------------------------------------------
GREEN "Administrator"
    All good - the clicks reach anything on screen.

AMBER "Not administrator"
    Clicks will not reach some games. Press the
    "Run as admin" button on the right and answer "Yes".


5) IF THE FILE DISAPPEARS ON ITS OWN
--------------------------------------------------------------
The program does not delete itself. Windows Defender may have
quarantined it - auto clickers get flagged often.

To get it back:
  Windows Security > Protection history >
  open the entry > Actions > Restore


6) REMOVING IT
--------------------------------------------------------------
Drag this folder to the recycle bin, that is all. The program
installs nothing, touches no registry keys, and writes no
files anywhere else.
